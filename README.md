# WEB-BASED INTEGRATED SYSTEMS

A university group project developed for **[WEB-BASED INTEGRATED SYSTEMS]** at TAR UMT.

## Project Information

- **Programme:** Diploma in Information Technology
- **Year / Semester:** Y1S3

## Overview

This project is a web-based food ordering and management system for an online burger shop called XBURGER. It allows customers to browse products, add items to a cart, place orders, and manage their profile and order history, while administrators can manage products, accounts, and order statuses from a separate dashboard. The system combines storefront and admin functionality into a single integrated PHP web application.

## Features

- Customer login, registration, and account management
- Product browsing with search, category filters, and price sorting
- Add-to-cart and checkout flow with quantity selection
- Order history and detailed order tracking
- User profile updates, avatar upload, and saved address management
- Admin dashboard for managing products, accounts, and orders
- Order status updates and product availability control

## Disclaimer

This project was developed as part of university coursework at TAR UMT.
It was completed collaboratively as a group project.
